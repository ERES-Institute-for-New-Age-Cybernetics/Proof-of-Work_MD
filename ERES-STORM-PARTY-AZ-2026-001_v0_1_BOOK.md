3. **ACT.** The engine names the next operator action (`next_action`).
4. **FEEDBACK.** An Operator writes new evidence with `update`. The DETAIL version bumps, the forecast recomputes, and P stays untouched.

Because the function reads evidence and changes its own output, the book's answer is live. Every correct use of it makes it more accurate.
